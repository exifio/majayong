# 결정메모 — 프론트엔드 착수 기준 (11/03 · 11/04 갱신)

개발패키지 v0.7 최종본 · 디자인 시스템 v0.2.1 최종본을 읽고 나온 정리 항목의 결정. 이 메모가 아래 문서의 해당 부분보다 우선하며, 다음 문서 개정 때 각 문서에 합친다. #9~#11은 M0 프론트엔드 착수 계획을 세우며 정한 권장안이다. **#12~#18은 11/04 화면 수정에서 정한 것이며, #6 · #11을 대신한다. #19~#23은 11/04 확정 버튼 뒤 상태를 그리며 낸 권고안을 그대로 확정한 것이다.**
